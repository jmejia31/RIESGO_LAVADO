## 1. Hallazgos confirmados

### 1.1 Respuestas HTTP fuera de orden
`MatricesRiesgosComponent.cargarEvaluaciones()` mantiene `subscribe()` independientes. Una respuesta anterior puede llegar después de una consulta nueva y sobrescribir `evaluaciones`, `totalRegistros`, `totalPaginas`, `errorEvaluaciones` o `cargandoEvaluaciones`.

### 1.2 Página solicitada mayor que el total disponible
`MatricesRiesgosRepository.ListarEvaluacionesPaginadasAsync()` valida `Pagina >= 1`, cuenta registros y calcula el `offset` directamente con la página solicitada. Si una consulta pide página 8 y el nuevo conjunto filtrado solo tiene 2 páginas, el contrato puede responder `Pagina=8`, `Items=[]`, `TotalPaginas=2`. La UI puede mostrar estados incoherentes como `Pág. 8 de 2`.

### 1.3 Page-size sin whitelist defensiva
La UI expone 10/20/50, pero `cambiarRegistrosPorPagina()` acepta cualquier valor numérico convertido con `Number(...)`. F4.2 debe limitar la operación a la whitelist institucional.

### 1.4 Navegación incompleta
Actualmente existen Anterior/Siguiente y resumen, pero no navegación compacta por números de página.

## 2. Diseño aprobado

### 2.1 Backend — normalización de página en una sola consulta
Después de `totalRegistros = COUNT(*)` y antes de calcular el offset:

```csharp
int totalPaginas = filtro.RegistrosPorPagina > 0
    ? (int)Math.Ceiling((double)totalRegistros / filtro.RegistrosPorPagina)
    : 0;

int paginaEfectiva = totalPaginas == 0
    ? 1
    : Math.Min(filtro.Pagina, totalPaginas);

int offset = (paginaEfectiva - 1) * filtro.RegistrosPorPagina;
```

El DTO de salida debe usar:

```csharp
Pagina = paginaEfectiva,
RegistrosPorPagina = filtro.RegistrosPorPagina,
TotalRegistros = totalRegistros
```

`TotalPaginas` continúa siendo la propiedad calculada del DTO.

Resultado esperado:
- 0 registros -> `Pagina=1`, `TotalPaginas=0`, `Items=[]`.
- página solicitada válida -> se conserva.
- página solicitada > total -> el servidor devuelve la última página válida en la misma solicitud.
- no se requiere segunda llamada correctiva Angular.

No modificar SQL estructural, tablas, secuencias ni ejecutar Oracle.

### 2.2 Frontend — cancelación + invalidación de respuesta
Implementar protección doble y pequeña:

```typescript
private suscripcionEvaluaciones: Subscription | null = null;
private secuenciaCargaEvaluaciones = 0;
```

En `ngOnDestroy()`:

```typescript
this.secuenciaCargaEvaluaciones++;
this.suscripcionEvaluaciones?.unsubscribe();
this.suscripcionEvaluaciones = null;
```

En cada `cargarEvaluaciones()`:
1. capturar snapshot de `buscar`, `estado`, `pagina`, `registrosPorPagina`;
2. incrementar `secuenciaCargaEvaluaciones` y guardar `solicitudId`;
3. cancelar la suscripción anterior;
4. poner loading=true/error=null;
5. suscribirse a la nueva consulta;
6. en `next` y `error`, ignorar cualquier callback cuyo `solicitudId !== secuenciaCargaEvaluaciones`.

Con HttpClient, `unsubscribe()` cancela la petición en curso; el identificador monotónico mantiene una segunda barrera defensiva.

### 2.3 Normalización de respuesta frontend
En la respuesta vigente:
- `items`: `Array.isArray(...) ? ... : []`;
- `totalRegistros`: número finito, entero, mínimo 0; inválido -> 0;
- `totalPaginas`: número finito, entero, mínimo 0; inválido -> derivar de `totalRegistros / pageSize`;
- `pagina`: usar `paginado.pagina` solo si es entero >=1 y compatible con `totalPaginas`; en caso contrario normalizar a 1 si total=0 o al rango `[1,totalPaginas]`;
- nunca permitir `pagina > totalPaginas` cuando `totalPaginas > 0`;
- la respuesta más reciente es la única que puede poner `cargandoEvaluaciones=false`.

### 2.4 Page-size institucional
Whitelist exacta: `10, 20, 50`.

`cambiarRegistrosPorPagina(valor)`:
- convertir a Number;
- aceptar solo enteros incluidos en whitelist;
- si inválido: no modificar estado y no consultar;
- si es igual al valor actual: no generar consulta redundante;
- si válido y distinto: set page-size, `pagina=1`, preservar búsqueda/estado y cargar una vez.

### 2.5 Cambio de página
`cambiarPagina(nuevaPagina)`:
- solo enteros finitos;
- rango 1..TotalPaginas;
- si `TotalPaginas=0`, no navegar;
- si coincide con página actual, no consultar;
- una navegación válida produce una sola consulta preservando búsqueda/estado/page-size.

### 2.6 Páginas visibles compactas
Crear `paginasVisibles` como `computed<number[]>`.

Candidatos recomendados:
`1`, `actual-2`, `actual-1`, `actual`, `actual+1`, `actual+2`, `total`.

Filtrar al rango 1..total, eliminar duplicados y ordenar.
En HTML insertar `…` cuando la diferencia con el número previo sea >1.

Ejemplo: `1 … 4 5 [6] 7 8 … 25`.

Cada botón debe:
- tener `aria-label="Ir a la página N"`;
- usar `aria-current="page"` en la página actual;
- quedar deshabilitado durante carga.

### 2.7 Estados de los controles durante loading
Deshabilitar durante `cargandoEvaluaciones()`:
- Anterior;
- Siguiente;
- números de página;
- page-size.

Búsqueda/Estado pueden seguir cambiando; una nueva consulta cancela/invalida la anterior.
