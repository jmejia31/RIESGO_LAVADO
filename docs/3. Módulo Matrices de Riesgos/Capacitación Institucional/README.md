## Custodia

Las plantillas completadas, listas firmadas, evaluaciones individuales, fotografías, correos y grabaciones deben mantenerse en la ubicación institucional autorizada con acceso restringido. No se deben agregar datos personales a Git sin autorización expresa. Este paquete contiene sólo plantillas vacías y ejemplos sintéticos; no certifica que la sesión haya ocurrido ni que existan evidencias.

## Mantenimiento

El contenido armoniza con la documentación funcional vigente: seis bloques, seis estados, guardado explícito y consulta consolidada por evaluación. No presenta nombres de roles como concesión automática de acceso ni fija versiones históricas como configuración actual. La institución debe validar el paquete antes de aprobarlo.
