# Cierre institucional - SGRLA-IHSS

Este directorio conserva los documentos institucionales que requieren aprobación, firma o evidencia externa antes del cierre productivo definitivo.

## RTO institucional

Documentos vigentes:

- [Acta RTO v1.1 - fuente canónica editable](./ACTA_RTO_INSTITUCIONAL_SGRLA_IHSS_v1_1.md)
- [Acta RTO v1.1 - copia física imprimible y firmable](./Acta_RTO_Institucional_SGRLA_IHSS_v1_1.pdf)

Estado:

```text
RTO_DOCUMENT_VERSION=1.1
RTO_PROPOSED=4 horas
INCIDENT_RESPONSE_TARGET=0 minutos
CATASTROPHIC_EXCEPTION=TRUE
RTO_DEFINED=FALSE
RTO_PENDING_INSTITUTIONAL_SIGNATURE=TRUE
```

El RTO no se considera institucionalmente aprobado hasta que la versión adoptada sea firmada por las autoridades competentes y archivada como evidencia.

## Pendientes institucionales restantes

```text
RPO_DEFINED=FALSE
INSTITUTIONAL_TRAINING_EXECUTED=FALSE
PRODUCTION_DEPLOYED=FALSE
```

La aprobación del RTO no sustituye la definición del RPO, la ejecución/registro de capacitación ni el despliegue productivo real.
