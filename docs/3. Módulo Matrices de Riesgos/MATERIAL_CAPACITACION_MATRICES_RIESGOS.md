# Material de capacitación — Matrices de Riesgos

## Ruta guiada

1. Ingresar con cuenta propia y comprobar rol.
2. Seleccionar `MATRIZ_RIESGOS_LAFT` y verificar que V1 está publicada.
3. Explicar que V2 está `DRAFT` y no vigente.
4. Crear/consultar riesgo, evaluación, controles y plan con datos de práctica.
5. Adjuntar solo archivos permitidos y revisar la evidencia.
6. Enviar a revisión; distinguir observación, rechazo y aprobación.
7. Consultar histórico y auditoría.
8. Abrir Consolidado, filtrar, generar preview y descargar Excel.

## Errores comunes

No compartir contraseña, no alterar resultados calculados, no intentar editar una versión publicada, no saltar preview, no descargar evidencias de otro caso y no tratar `GTIC`/`MITIGAR` históricos como decisiones institucionales.

## Seguridad

Cerrar sesión en equipos compartidos. Reportar 403, acceso a un registro ajeno, archivos rechazados inesperadamente o diferencias de cálculo. El backend es la autoridad; el navegador no concede permisos.
