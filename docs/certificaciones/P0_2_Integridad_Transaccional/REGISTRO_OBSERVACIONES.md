# Registro de observaciones

- TX-07 no conserva una consulta SQL global del total de versiones vigentes de la familia; se mantienen únicamente las versiones A/B examinadas.
- TX-10A/TX-10B no conservan el cuerpo HTTP 409 completo; las filas Oracle antes/después y las dependencias permanecen documentadas.
- El paquete independiente TX-10 y la firma independiente no están disponibles localmente: `MISSING_LOCAL_SOURCE`.
- La limpieza local completa de temporales sensibles queda pendiente de procedimiento autorizado; no se publica material restringido.
- `TX12_FRONTEND=NOT_VERIFIED`, GTIC y H08 siguen fuera del alcance de este expediente.
- `BLOCK10_AUTHORIZED=NO`.
