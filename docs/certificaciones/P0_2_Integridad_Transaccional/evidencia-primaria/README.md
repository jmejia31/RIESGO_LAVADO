# Evidencia primaria sanitizada

Estos archivos son registros textuales sanitizados y etiquetados derivados de afirmaciones concretas del dictamen independiente de la issue #23. No se presentan como capturas HTTP, SQL, auditoría o logs originales: las fuentes binarias/externas no están disponibles en este checkout y permanecen `MISSING_LOCAL_SOURCE` en el manifiesto. No contienen identificadores personales, hosts, credenciales, tokens, connection strings ni datos de clientes.

`SOURCE_TYPE=DICTAMEN_TRANSCRIPTION`; `RAW_CAPTURE_AVAILABLE=NO`; `REVIEW_STATUS=READY_FOR_INDEPENDENT_REVIEW`.
Cada archivo `TX-*.md` es una transcripción textual sanitizada de una fuente primaria identificada por paquete y SHA-256. No es una nueva ejecución ni sustituye una fuente restringida. `TX-01`, `TX-02`, `TX-12-backend`, `TX-05`, `TX-07`, `TX-13`, `TX-08`, `TX-09`, `TX-10A` y `TX-10B` están indexados en `../PRIMARY_EVIDENCE_INDEX.json`.
